## 🚀 Projects

### Project 01 – Python & Data Processing

Topics covered:
- Python fundamentals and introduction.
- Data cleaning and preprocessing.
- People You May Know – friend recommendation logic.
- Pages You Like – page recommendation logic.
- Dictionary and Set operations.
- Loops, conditions and data manipulation.

### Project 02 – Coders of Bengaluru

A practical data processing project focused on extracting and organizing Instagram profile information.

Topics covered:
- Reading and processing raw text data.
- String manipulation and parsing.
- Extracting usernames, posts, followers and following.
- Converting follower counts (K/M) into numbers.
- Organizing data into Python dictionaries.
- Counting profile categories.
- Finding profiles with maximum followers and following.
- Exporting cleaned data into JSON format.
